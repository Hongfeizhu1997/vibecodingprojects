§1Scope Definition

In Scope

  • #1 ODT attribute change impact analysis + Booking Impact
  • #4 MT Announcement auto-capture
  • #12 PN master data query (ad-hoc reports)
  • Teams Bot conversational interface
  • RAG knowledge base (PN workflows / rules / approvals)
  • Approval notifications (notify only — no execution)

Out of Scope

  • #2 Auto-generate POR / #3 Duplicate PN check
  • #5 PN lifecycle management
  • Web Persona Workspace
  • System write operations (Cost / Price)
  • Cost Agent / Price Agent / Lifecycle Agent
  • Approval workflow execution
Why Knowledge Agent first? All 3 scenarios are read-only → zero destructive risk. Immediate value (team does these daily). Validates API / RAG / Teams Bot feasibility. Builds business trust before Waves 2–4.

§5Teams Bot Interaction Design

Three Interaction Modes

@Mention Q&A
User @Agent sends query → Agent returns result. Supports single queries and follow-up clarification.
Push Notifications
MT Announcement auto-pushed to GPS PM / Pricing Team channels with card-style summaries.
Approval Notifications
ODT change analysis complete → DM relevant stakeholders. Wave 1: notify only, no execution.
