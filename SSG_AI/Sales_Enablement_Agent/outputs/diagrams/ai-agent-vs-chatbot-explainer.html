Section 1

01 Spark Helped — But Hits a Natural Ceiling

✅ What Spark Does Well

  • FAQ lookups & process guidance
  • Moved team from docs → asking AI

❌ What Spark Cannot Do

  • Call system APIs (ODT, CPM, Concord)
  • Cross-reference live data across systems
  • Proactively monitor & push alerts
  • Understand Booking data structures

⚠️ Vibe Coding & Codex Agents

  • Single-user, single-system scripts
  • No security boundaries or audit trail
  • Zero knowledge sharing across tools
  • Dies when the builder leaves
All three are point solutions. They prove the demand is real — but each rebuilds from scratch for every scenario.

Section 4

04 Built on Vetra — One Platform, Multiple Business-Line Agents

The SSG Agent isn't a standalone project. It runs on Vetra — Lenovo's company-level AI Agent orchestration platform. Build once, serve every business line.

🧠 Memory

  • Cross-session state persistence
  • GPS PM preferences & approval history
  • Shared infra — not rebuilt per agent

🔧 Skills

  • Reusable capability registry (Skill Hub)
  • Versioned & independently upgradeable
  • SSG: PN / Cost / Pricing / Lifecycle

🛡️ Constraints

  • Rules engine (BCPF via Signavio)
  • Auto-Execute vs. Requires Approval
  • "Price change >15% = Director sign-off"

📦 Sandbox

  • Isolated execution per agent
  • No cross-contamination across lines
  • SSG ↔ SPEP / SCFE / CPM / ICP safely
Think iOS / Android — the operating system. SSG Sales Enablement Agent is one app on the platform. IDG CS SW Agent is another — sharing the same Memory, Skills, Constraints, and Sandbox infrastructure. Every future Lenovo Agent inherits this foundation at zero marginal platform cost.
