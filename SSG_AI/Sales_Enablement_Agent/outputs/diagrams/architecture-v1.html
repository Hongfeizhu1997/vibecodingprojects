02 Vetra Core Components — What Powers the Agent

Four components work together to make the Agent capable, safe, and continuously improving — not just a chatbot with a rulebook.

🧠 Memory

Remembers context across conversations — short-term, long-term, and domain knowledge.

Example: "Cost for PN-88421?" → "And channel price?" — knows you're still on PN-88421. Learns Sarah's template preferences over time. Grounded on EKP + BCPF (Signavio).

🔧 Skills

Reusable capabilities packaged as independent modules — each versioned, tested, and pluggable.

Example: PN Creation Skill handles duplicate detection, POR form generation, and SPEP submission. Upgrading this Skill doesn't affect Cost Calculation or Pricing Skills.

🛡️ Constraints

Rules, permissions, and boundaries that keep the Agent operating safely within defined limits.

Example: PN creation requires manager approval before SPEP submission. Pricing changes above 15% deviation trigger mandatory review. Low-confidence recommendations route to human.

📦 Sandbox

Isolated execution environment — the Agent tests actions here before touching real systems.

Example: When generating a new PN draft, the Agent builds and validates it in Sandbox first. Only after all checks pass does it push to SPEP. No live system is touched without verification.
How they work together: Memory provides context → Skills execute tasks → Constraints enforce boundaries → Sandbox ensures safety. All four sourced from the Lenovo Skill Hub enterprise platform.

07 The Bottom Line

13 scenarios. 6 roles. 5 systems. One platform. Four specialized Agents deployed over four phases — starting with zero-risk read-only lookups and progressing to approval-gated financial operations.

Phase 1 critical path: confirm system APIs, populate EKP with SME input, stand up RAG Pipeline on EKP for Teams Q&A. 6 weeks. Low risk. High learning.

This is a teammate, not a replacement. The GPS team's expertise is irreplaceable. The Agent handles the mechanical work: lookups, cross-checks, calculations, approval routing.
