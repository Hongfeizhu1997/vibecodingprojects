We build the top four layers. The bottom two — Lenovo Hybrid AI Platform and the six business systems — already exist. The Agent Orchestration Engine sits between them, connecting AI intelligence to operational systems through a safety-gated pipeline.
Harness Engineering paradigm. This architecture follows the same evolution path AI Config validated internally: Prompt Engineering → Context Engineering → Harness Engineering. The core principle — humans set objectives & boundaries, agents autonomously plan & execute, skills serve as reusable capabilities — is implemented through our Safety Layer (boundaries), Master Agent + Sub-Agents (autonomous execution), and 5 specialized Skills (reusable biz capabilities).

02 Memory System

🧠 Short-Term Memory

Remembers your current conversation — like holding a discussion without repeating context.

Example: "Cost for PN-88421?" → "And channel price?" — knows you're still on PN-88421.

📝 Long-Term Memory

Learns your preferences over weeks — like a colleague who knows how you work.

Example: Sarah prefers a specific PN draft template. After 3 uses, Agent defaults to it.

📚 Domain Knowledge Base

Stores PN lifecycle rules, pricing logic, approval policies — the team's collective playbook.

Example: New TMO asks "when to retire a PN?" → retrieves exact policy, not an AI guess.

💼 Business Impact

Without memory, every conversation starts from zero. With it, the Agent builds working knowledge of your role and tasks.

All data stays within Lenovo infrastructure.

08 The Bottom Line

This is a teammate, not a replacement.

The GPS team's expertise — knowing which tier fits a new MT, judging when to extend vs. create a PN, deciding whether a benchmark warrants a price change — is irreplaceable. The Agent handles the mechanical work surrounding these decisions: lookups, cross-checks, calculations, approval routing, email chasing.

13 scenarios. 6 roles. 6 systems. One platform. Four specialized Agents deployed over four waves — starting with zero-risk read-only lookups and progressing to approval-gated financial operations.

Wave 1 critical path: confirm system APIs, build knowledge base with SME input, stand up Knowledge Agent for Teams Q&A. 4–6 weeks. Low risk. High learning.
