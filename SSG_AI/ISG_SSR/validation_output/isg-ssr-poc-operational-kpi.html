Metric Alignment Note: This report aligns ISG SSR POC (offline holdout) results to the IDG SSR Phase 1 analysis framework the business is already familiar with.

Key Definition: • Hit = Label AND SLA both match between model prediction and ground truth. This is the strictest accuracy measure: the model must get both the warranty product and the service level right.
• Acceptance Rate (IDG) = Top-1 Hit Rate (POC): "Seller kept the default recommendation" maps to "Model's #1 prediction matches actual choice (label + SLA)."
• Coverage (IDG) → N/A (POC): All holdout rows have predictions (100% coverage).
• AI vs Non-AI (IDG) → Confidence Tier (POC): Recommendation source stratification becomes confidence tier (High/Mid/Low).
• Config Origin (IDG) → Warranty Type (POC): Both represent "acceptance difficulty across contexts" — Warranty Type is the strongest performance differentiator in this POC.
• Limitation: This is offline holdout simulation, not live transactions. Cannot observe Change Rate, Attach Rate, or real seller behavior. Hit Rate measures "how accurate is the model" but not "how much do sellers trust it."

I. Mix Effect Diagnosis (Warranty Type Composition)

Premier (87.8% of volume, 86.8% Top-1) inflates the blended rate by +1.6pp. PSP Server at 7.1% and 68.5% drags it down by -1.2pp. If PSP Server share grows to 15% in production (e.g., more enterprise deals), the blended Top-1 would drop from 85.2% to ~82.5% purely from mix shift — not model degradation.

J. SLA Mismatch Analysis — The 4.7pp Penalty

108 contracts (4.7%) lose Top-1 hit due to SLA mismatch alone. The model correctly picks the warranty product but assigns the wrong service level. This is a distinct failure mode from the PSP Server rank-1 problem — it's a systematic SLA discrimination issue.

MetricValue
Top-1 Label-only Hit2,064 (89.9%)
Top-1 Label + SLA Hit1,956 (85.2%)
SLA Mismatch Gap108 contracts
SLA Match Rate (all predictions)93.1%
Hypothesis: SLA is binary in this dataset (24x7 4hr Resp vs Next Business Day). The model may not be treating SLA as a separate prediction target — it's embedded in the label string. Recommendation: separate SLA into an independent classification head with its own loss function. The 93.1% overall SLA match rate suggests the signal exists; the 108 misses suggest it's not being optimized directly.
