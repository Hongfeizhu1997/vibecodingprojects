POC ↔ Production Mapping Note

口径对齐说明：本报告将 ISG SSR POC（Holdout 离线预测）的结果对齐到业务方熟悉的 IDG SSR Phase 1（真实交易记录）分析框架。

关键口径差异： • Acceptance Rate（IDG）= Top-1 Match Rate（POC）："卖家保留默认推荐"对应"模型 #1 推荐命中真实选择"。语义一致：推荐被采纳。
• Coverage（IDG）→ 不适用（POC）：Holdout 集所有行都有预测，Coverage=100%。报告中标注"数据覆盖范围"作为替代。
• AI vs Non-AI（IDG）→ Confidence Tier（POC）：推荐来源分层变为置信度分层（High/Mid/Low），同为"推荐可信度梯度"。
• Config Origin（IDG）→ Warranty Type（POC）：同为"不同上下文下的接受难度差异"——POC 中 Warranty Type 是最大的区分维度。
• 本分析的局限：这是离线 Holdout 模拟，不是实时交易记录。无法观测 Change Rate（卖家替换推荐）、Attach Rate（最终选不选服务）等实时行为指标。Hit Rate 只能衡量"推荐准不准"，不能衡量"卖家信不信"。

⚠ PSP Server Deep Dive

PSP Server Top-1 is only 68.5% — 51 out of 162 contracts missed. Top-2 only adds 15 more hits (77.8%). This is a rank-1 problem, not a coverage problem: model ranks the wrong label #1, but the correct answer is often in Top-2/3. The gap is concentrated in 60-Month PSP Server (48.8% — see Section D). Recommendation: audit PSP Server training data volume and class balance.

C. Match Rate by Confidence Tier (Aligns with IDG "AI vs Non-AI")

Confidence calibration is inverted. Low-confidence tier has the highest hit rate (90.6%) and High-confidence tier the lowest (88.6%). The model is overconfident on cases it gets wrong and underconfident on cases it gets right. This means confidence scores cannot be used for escalation logic — a common calibration issue in multi-class recommenders trained on imbalanced data.

PSP Server (7.1%) gets lower probability but failures are hidden in the long tail. Fix: calibrate using Platt scaling or isotonic regression on the validation set.

H. Mix Effect Diagnosis (Warranty Type Composition)

Unlike IDG's New CTO/Copied CTO mix effect, ISG POC has a Warranty Type mix effect. Premier (87.8%, 92.1% Top-1) inflates the overall Top-1 by +2.2pp. If PSP Server share grows from 7.1% to 15%, the blended Top-1 would drop from 89.9% to ~87.4% purely from mix shift — even with no model degradation.
