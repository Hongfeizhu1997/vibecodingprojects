Part 5: Improvement Plan for Production

Based on the error patterns identified above, we propose 4 targeted improvements. P0 items address the largest error sources and must be completed before expanding beyond Premier scope. P1 items improve production readiness during Pilot.

P0 Strengthen Term Duration Prediction

46.8% of all misses | 159 contracts | Same type, wrong term
The problem: The model confuses 36-month and 60-month warranty terms within the same warranty type. This is the single largest error source. The 60M→36M direction (76 cases) is particularly harmful — the customer wants 5-year coverage, the model suggests 3-year.
Fix: Add features that correlate with term duration: hardware product generation/lifecycle stage, historical term preferences by customer segment, term distribution by hardware price tier, and subsegment patterns (Enterprise tends toward longer terms).

P0 Expand PSP Server Training Coverage

PSP Server Top-1: 68.5% | Only 7.1% of training data | Model defaults to Premier
The problem: PSP Server appears in only 7.1% of training data. When uncertain, the model defaults to Premier — 71% of PSP Server misses are misclassified as Premier. The model recognizes PSP Server (Top-3 covers 88.9%) but lacks confidence to rank it #1.
Fix: Augment training data with additional PSP Server samples. Apply class-weighted loss to penalize PSP Server misclassification more heavily.

P1 Improve Adjacent Product Differentiation (SLA Tier)

31.8% of misses | 108 contracts | Same type+term, different SLA
The problem: Within the same warranty family (e.g., "36M Premier"), the model confuses the two SLA tier variants — 24x7 and NBD. These are distinct products. The error is balanced (51 NBD→24x7, 57 24x7→NBD), suggesting the model needs better differentiation features, not a directional bias correction.
Fix: Add features correlated with SLA tier: hardware criticality (mission-critical servers → 24x7), customer industry (healthcare/finance → 24x7), hardware price tier (higher HW value → higher SLA), and subsegment (LE/PS → 24x7, SM/GA → NBD).

P2 Handle Long-Tail Rare Product Variants

48-Month: 52.9% hit rate | 72-Month: 0% | Small volumes
The problem: 48-month and 72-month warranties are too rare for reliable model learning. These will improve naturally with more data.
Fix: No model changes needed now. During Pilot, flag rare-term recommendations for mandatory seller review. Retrain after accumulating 3–6 months of production data.

Recommended Pilot Approach

Recommendation: Launch Pilot with Premier warranty scope only (87.8% of volume, 86.8% product match). The model is production-ready for this segment today. Expand to PSP Server and ESS after P0 fixes validated.
