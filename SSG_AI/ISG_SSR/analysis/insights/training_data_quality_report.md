## 🔴 严重（必须修复）

### 1. SVC bind 标签下 svccontractprice 全部等于 hwcontractprice

- **影响行数**: 716 / 716 (100%)
- **描述**: `SVC bind HW in item` 标签的全部 716 行，服务合同价等于硬件合同价（精确到分）。
- **分析**: 业务上服务价格几乎不可能恰好等于硬件价格。疑似数据抽取时服务价格字段被硬件价格覆盖。
- **建议**: 回到源系统（SAP/CLFO）核对这 716 行的真实服务价格。如果源数据确实如此，需要业务确认是否为"硬件包含服务"场景（零价服务通过硬件捆绑体现）。

### 2. HW bind 标签下 46% 行缺少服务合同价

- **影响行数**: 7,276 / 15,089 (48.2%)
- **描述**: `HW bind SVC in cmlfo` 标签下近一半的行 `svccontractprice` 为空。
- **影响**: 模型无法从这些行学到硬件-服务的价格关系。
- **建议**: 排查是否抽取逻辑遗漏了部分合同的服务价格，或这部分合同确实未购买服务（如果是，应打标签区分而非留空）。

---

## 🟡 中等（影响模型质量）

### 3. HW bind 行有服务价格但无服务 PN

- **影响行数**: 7,813 行（占 HW-bind 中有价格行的 100%）
- **描述**: 有 7,813 行同时有 `hwcontractprice` 和 `svccontractprice`，但 `svc_product_id` 全为空。你知道服务卖了多少钱，但不知道卖的是哪个 PN。
- **影响**: 无法进行服务推荐——模型需要知道"买了什么硬件 → 推荐什么服务 PN"。
- **建议**: 在 CLFO/SAP 源系统中找到这 7,813 行的服务 PN 映射。

### 4. 两套数据结构未统一

- **描述**: 数据存在两种形态：

| | HW bind SVC in cmlfo | SVC bind HW in item |
|---|---|---|
| 行数 | 15,089 | 716 |
| svc_product_id | 全空 | 716 行有 |
| svccontractprice | 7,813 行有 | 716 行有（但等于 hw 价格） |
| hwlistprice | 13,330 行有 (88%) | 183 行有 (26%) |

- **分析**: 两种标签来自不同数据源（CLFO vs Item-level），无合同同时出现在两边。
- **建议**: 训练前需明确：①用哪种标签做主训练集？②两种标签的字段覆盖率不同，如何合并或各自处理？

### 5. 硬件列表价 10% 缺失

- **影响行数**: 1,576 / 15,805 (10.0%)
- **明细**: SVC bind 组缺失最严重（533/716 = 74%），HW bind 组 1,043/15,089 (6.9%)
- **影响**: `hwlistprice` 缺失意味着无法计算硬件折扣率（Pen Rate），而 ISG 定价的核心是 Pen Rate × HW Price。
- **建议**: 补充缺失的硬件列表价。SVC bind 组 74% 缺失尤其严重。

### 6. 服务/硬件价格比分布极端

- **样本量**: 7,813 行（HW bind 中两价均有）
- **分布**:

| 分位 | SVC/HW 价格比 |
|------|:---:|
| P0 (最小) | 0.0007% |
| P5 | 0.027% |
| P25 | 0.15% |
| P50 (中位数) | 0.37% |
| P75 | 3.2% |
| P95 | 6.7% |
| P100 (最大) | 18.0% |

- **分析**: 中位数 0.37% 意味着 $100K 硬件配 $370 服务。在 ISG 场景中，保修/增配服务的典型占比应更高（5-15%）。建议抽查 P25 以下区间的样本，确认是否存在数据错误。

## 🟢 轻微（可接受，需确认）

### 7. 疑似重复行（72 组，172 条冗余）

- **描述**: 相同 `(合同号, HW_PN, 服务PN)` 组合出现 2-9 次。
- **分析**: 由于 `svc_line_item_id` 在 HW-bind 组全空，无法判断是真实不同的行项目还是数据重复。
- **建议**: 如果这些行其他字段（价格、日期等）完全相同 → 去重；如果不同 → 保留，说明是同一合同下同一套硬件的多次同价服务。

### 8. 时间跨度仅 3 个月

- **范围**: 2026-04-01 ~ 2026-06-29
- **影响**: 无季节性覆盖，模型泛化能力受限。如业务有 Q-end 冲刺效应（6 月底），数据会偏斜。

### 9. 服务 PN 种类偏少（140 vs 硬件 9,549）

- **比例**: 硬件:服务 = 68:1
- **分析**: ISG 服务 catalog 本身可能不大，但 140 种 PN 是否覆盖了全部可推荐的服务？建议与 catalog 团队确认。

### 10. baseterm / category2-5 统一缺失

- **影响行数**: 743 (4.7%)
- **特征**: 这 5 个字段从不单独缺失——要么全有，要么全空。
- **建议**: 确认这 743 行是否属于无保修信息的数据源切片。
